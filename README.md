# floppy_mac

Read-only драйвер для macOS, монтирующий **физические дискеты** (MS-DOS FAT12/16)
через [Greaseweazle](https://github.com/keirf/greaseweazle) прямо в Finder.
Свой стек на Rust: флукс с Визеля → MFM-декодер → FAT → FUSE. Без Xcode, без
kext, на Full Security (Apple Silicon).

## Смонтировать живую дискету

```sh
cargo build --release

# 1. найти порт Greaseweazle
./target/release/floppy_mac --list-devices          # → /dev/tty.usbmodem…

# 2. вставить дискету и смонтировать
./target/release/floppy_mac /tmp/floppy --device /dev/tty.usbmodem11201

# 3. в другом окне — файлы дискеты в Finder / терминале
open /tmp/floppy
ls -la /tmp/floppy

# извлечь: umount /tmp/floppy   (или Ctrl-C в окне драйвера)
```

Первое монтирование прогревает метаданные (~1 с), дальше просмотр мгновенный;
данные читаются по требованию и кэшируются подорожечно.

## Опции

```
floppy_mac <точка> [источник] [опции]
floppy_mac --list-devices
```

| Аргумент            | Назначение                                                        |
|---------------------|-------------------------------------------------------------------|
| `<точка>`           | Точка монтирования                                                |
| `--device <порт>`   | Живая дискета через Greaseweazle на указанном serial-порту        |
| `--image <файл>`    | Смонтировать готовый образ `.img` (без железа)                    |
| *(без источника)*   | Демо hello-FS (один синтетический `README.txt`)                   |
| `--list-devices`    | Показать доступные serial-порты и выйти                           |
| `--probe`           | Диагностика чтения без монтирования (нужен `--device`)            |
| `--recover`         | Best-effort: отдавать данные даже с плохим CRC, пропавшие секторы — нулями, в конце — отчёт о битых секторах. По умолчанию битый сектор → ошибка ввода-вывода |
| `--unit <n>`        | Номер привода на шине (по умолчанию `0`)                          |
| `--revs <n>`        | Оборотов на чтение дорожки (по умолчанию `3`; больше — надёжнее для слабых дискет) |

Логи: `RUST_LOG=info` (геометрия, ретраи), `RUST_LOG=debug` (попадания кэша).

### Проблемные дискеты

Слабые секторы драйвер дочитывает бо́льшим числом оборотов (3 → 6 → 9). Если
сектор всё равно не читается — по умолчанию отдаётся ошибка (файл не портится).
Чтобы вытащить данные несмотря на осыпавшиеся секторы:

```sh
floppy_mac /tmp/floppy --device /dev/tty.usbmodem11201 --recover
```

## Требования

- macOS (проверено на macOS 26, Apple Silicon)
- [macFUSE 5+](https://macfuse.github.io/) (юзерспейс, kext не нужен)
- Greaseweazle (v1.x) + 3.5″/5.25″ дисковод
- Rust / `cargo`

## Как это устроено

```
Finder → FUSE (fuser) → актор (кэш дорожек) → FatFs (крейт fatfs)
                                             → BlockSource:
                                                 ImageFile (.img)
                                                 Greaseweazle → свой протокол (gw.rs)
                                                              → свой MFM-декодер (mfm.rs)
```

Два трейта-шва — `BlockSource` (откуда байты) и `Filesystem` (как толковать) —
позволяют добавлять новые форматы/источники, не трогая остальное.

## Ограничения

- Только чтение. FAT12/16 (MS-DOS). Другие форматы (Amiga, TR-DOS, …) — через
  новую реализацию `Filesystem`.
- Монтирование — явной командой; авто-детект вставки пока не реализован.

## Лицензия

GPL (следствие линковки с macFUSE). Хост-протокол Greaseweazle реализован
самостоятельно по официальному public-domain `usb.py` — стороннего кода в
проекте нет.
